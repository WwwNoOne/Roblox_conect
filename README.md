# Abismo

Terror cooperativo en Roblox para 2–4 jugadores. El equipo baja en submarino por cuevas submarinas generadas con salas modulares, recoge tesoros para pagar la cuota, esquiva criaturas (sin combate) y trata de llegar lo más profundo posible.
